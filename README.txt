NADYA SACCHI — PORTFOLIO VISUAL

Esta versión separa el portfolio en páginas independientes:
- index.html: portada y navegación por áreas
- writing.html, voice.html, translation.html, admin.html, visual.html, about.html, services.html: páginas por área

IMPORTANTE: copiar estos HTML dentro de la carpeta raíz del portfolio existente, conservando intactas las carpetas de imágenes y audios con sus nombres actuales. No mover ni renombrar archivos de las carpetas de contenido.
Las vistas previas se muestran directamente en formato 16:9. Al pulsar una imagen, se abre en tamaño completo.
No hay sección de contacto ni enlaces a GitHub dentro del sitio.

Las rutas de las ilustraciones se buscan con varias extensiones (.png, .jpg, .jpeg, .webp). Si una caricatura tiene otro nombre exacto, habrá que ajustar únicamente esa ruta, sin cambiar el nombre del archivo.
